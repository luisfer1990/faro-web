# Recursos para la próxima revisión de Faro Web

`capturas/` contiene los PNG recortados con fondo transparente, incluidas las notificaciones. `videos/` contiene cuatro clips MP4 en 720p, sin audio.

- `recorta-y-traduce.mp4` muestra la selección real y el resultado en inglés. El montaje omite la espera entre ambos.
- `copia-y-traduce.mp4` recrea el aviso automático a partir de la interfaz de Faro y está identificado como recreación dentro del clip.
- `musica-y-letras.mp4` y `modo-fantasma.mp4` proceden de las grabaciones de Faro.
- `portada-sin-musica.png` es la opción sin letras ni portada de álbum.

Los recursos quedan listos para revisar e integrar en la página.
