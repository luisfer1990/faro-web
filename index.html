Lo que quizá quieras saber.

Respuestas breves antes de hacerle sitio a Faro en tu escritorio.

¿En qué versiones de Windows funciona?

Faro está disponible para Windows 10 y Windows 11.

¿Puedo elegir la forma y el aspecto de la isla?

Sí. Puedes usar el modo cápsula o notch, elegir tema Claro u Oscuro y fijar las pestañas que más usas.

¿Mis archivos se suben a internet?

La conversión de archivos, las capturas y el OCR se procesan localmente. Al enviar un archivo al móvil por QR, la transferencia se hace en la misma red Wi-Fi. Letras, clima o traducción pueden usar servicios externos cuando activas esas funciones.

¿Cómo abro la barra de comandos?

Presiona Ctrl + Alt + K. También puedes usar Ctrl + Alt + V para pegar texto sin formato.

¿Está disponible en español e inglés?

Sí. Faro incluye ambos idiomas.
